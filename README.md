A responsive, runnable recreation of the **HTML All Tags** visual reference shown in the supplied 28-second screen recording.

## Sections reproduced from the video

1. **Basic HTML Tags** — `html`, `head`, `body`, `div`
2. **Text & Content Tags** — heading levels (`h1`–`h6`), `p`, `a`, `strong`, `em`, `mark`, `blockquote`, `code`
3. **Media & Lists** — `img`, `ul`, `ol`, `pre`
4. **Forms & Controls** — `input`, `button`, `select`, `textarea`, `form`, `progress`
5. **Semantic HTML** — `header`, `nav`, `article`, `section`, `aside`, `footer`
6. **Advanced Tags** — `table`, `details`, `hr`, `abbr`

The visible labels and descriptions are kept close to the recording. The media thumbnail is represented with a self-contained CSS laptop illustration so the project has no external image dependency.

## Run

Extract the ZIP and open `index.html` in a modern browser. No package installation, build step, server, or external dependency is required.

## Files

- `index.html` — semantic page structure and tag examples
- `style.css` — dark navy grid background, cyan accents, responsive two-column cards and hover states
- `script.js` — small interactive button and demo form feedback
- `README.md` — project notes and source accuracy

## Source accuracy note

The screen recording shows the rendered reference page, not its original source editor. Therefore, no hidden original HTML/CSS/JavaScript can be literally extracted from this video. This project recreates the visible page design, text, card categories and sample controls from the frames. The underlying implementation is newly written and runnable, rather than a claim that every line is the original author's source code.
